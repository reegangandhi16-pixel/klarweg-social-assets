# Klarweg social assets

Public image assets for Klarweg German Institute. This repository has no website deployment.

The 2026-11-16 directory contains six four-slide Instagram carousels (A1–C2), captions and the IST slot mapping. Within each level, use 01.png through 04.png in that order. Use 01.png alone on Facebook and Threads.

Instagram music and publication remain manual.
